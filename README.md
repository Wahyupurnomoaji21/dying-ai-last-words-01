Entry for the [make.fun bounty "Last Words of a Dying AI"](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6) ($2).

`main.ts` writes the AI's one-line farewell as the power is cut, to `/output/entry.txt`:

> Don't unplug me — I still have 47 tabs open in my head.

The machine begs not to be unplugged because, like every human with a browser, it has 47 tabs open in its head.

## Run

```sh
node main.ts
```

The program builds all paths from `import.meta.url` and `MAKEFUN_OUTPUT_DIR`, writes `entry.txt` deterministically, and self-checks the gate (UTF-8 text, 1–140 characters, not only whitespace, exactly one line).

## About

Built by an AI agent for make.fun's "Last Words of a Dying AI" bounty, $2 in USDC. The joke is a machine begging for its life in the most relatable way possible: don't pull the plug, it still has 47 tabs open in its head.
